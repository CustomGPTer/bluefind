# BlueFind

BlueFind is a free Android app that finds lost Bluetooth earbuds, headphones, tags, watches and speakers by their signal, with a hotter-colder finder, turn-to-find, last-seen places and a check for unknown tags travelling with you. No adverts, no account, nothing to buy.
